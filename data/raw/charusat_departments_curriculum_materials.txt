1. FACULTY OF TECHNOLOGY & ENGINEERING (CSPIT & DEPSTAR)
================================================================================

1.1 COMPUTER ENGINEERING (CE) & INFORMATION TECHNOLOGY (IT) - CSPIT & DEPSTAR
--------------------------------------------------------------------------------
• Core Subjects & Recommended Reference Textbooks:
  1. Data Structures and Algorithms (DSA):
     - Textbooks: "Data Structures Using C and C++" by Reema Thareja; "Introduction to Algorithms" (CLRS) by Cormen, Leiserson, Rivest, Stein.
     - Lab Focus: Array, Linked List, Stack, Queue, Trees (AVL, Red-Black), Graphs (Dijkstra, Prim, Kruskal), Dynamic Programming in C++ and Python.
  2. Database Management Systems (DBMS):
     - Textbooks: "Database System Concepts" by Silberschatz, Korth, Sudarshan; "Fundamentals of Database Systems" by Elmasri & Navathe.
     - Lab Focus: SQL queries, Normalization (1NF to BCNF), Relational Algebra, Transactions & Concurrency Control, PostgreSQL & MongoDB.
  3. Operating Systems (OS):
     - Textbooks: "Operating System Concepts" by Silberschatz, Galvin, Gagne; "Modern Operating Systems" by Andrew S. Tanenbaum.
     - Lab Focus: Linux shell scripting, Process Scheduling algorithms (FCFS, SJF, Round Robin), POSIX Threads, Semaphore Synchronization, Deadlock avoidance (Banker's Algorithm).
  4. Computer Networks (CN):
     - Textbooks: "Computer Networks" by Andrew S. Tanenbaum; "Data Communications and Networking" by Behrouz A. Forouzan.
     - Lab Focus: OSI & TCP/IP stack implementation, Socket programming, Subnetting/VLSM calculations, Wireshark packet capture, Cisco Packet Tracer network simulation.
  5. Theory of Computation & Automata (TOC):
     - Textbooks: "An Introduction to Formal Languages and Automata" by Peter Linz; "Introduction to Automata Theory, Languages, and Computation" by Hopcroft, Motwani, Ullman.
     - Key Concepts: DFA, NFA, Regular Expressions, Context-Free Grammars (CFG), Pushdown Automata (PDA), Turing Machines, Halting Problem.
  6. Object Oriented Programming with Java / C++:
     - Textbooks: "Java: The Complete Reference" by Herbert Schildt; "Object-Oriented Programming with C++" by E. Balagurusamy.
     - Lab Focus: OOP Concepts (Inheritance, Polymorphism, Encapsulation, Abstraction), Exception Handling, Multithreading, Generics, JDBC.
  7. Cloud Computing & DevOps:
     - Textbooks: "Cloud Computing: Principles and Paradigms" by Rajkumar Buyya; AWS Official Architecture Documentation.
     - Lab Focus: AWS EC2, S3, IAM, Docker Containerization, CI/CD with GitHub Actions, Kubernetes clustering.

1.2 ARTIFICIAL INTELLIGENCE & MACHINE LEARNING (AI & ML) - CSPIT
--------------------------------------------------------------------------------
• Core Subjects & Recommended Reference Textbooks:
  1. Foundations of Machine Learning:
     - Textbooks: "Pattern Recognition and Machine Learning" by Christopher Bishop; "Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow" by Aurélien Géron.
     - Lab Focus: Supervised Learning (Linear/Logistic Regression, Decision Trees, Random Forests, SVM), Unsupervised Learning (K-Means, PCA), Model Evaluation (Precision, Recall, ROC-AUC).
  2. Deep Learning & Neural Networks:
     - Textbooks: "Deep Learning" by Ian Goodfellow, Yoshua Bengio, Aaron Courville.
     - Lab Focus: Multi-Layer Perceptrons, Backpropagation calculus, CNNs (ResNet, VGG) for image classification, RNNs & LSTMs for sequence modeling, PyTorch & TensorFlow GPU workflows.
  3. Natural Language Processing (NLP) & Large Language Models:
     - Textbooks: "Speech and Language Processing" by Dan Jurafsky & James H. Martin.
     - Lab Focus: Tokenization, TF-IDF, Word2Vec, Transformers Architecture, Attention Mechanisms, Fine-tuning HuggingFace LLMs, LangChain RAG pipelines.
  4. Computer Vision (CV):
     - Textbooks: "Computer Vision: Algorithms and Applications" by Richard Szeliski; "Learning OpenCV" by Gary Bradski.
     - Lab Focus: OpenCV image filters, Feature extraction (SIFT/ORB), Object detection with YOLOv8, Image segmentation with U-Net.
  5. High-Performance GPU Computing & AI Infrastructure:
     - Focus: NVIDIA CUDA C/C++ programming, TensorRT inference optimization, Distributed PyTorch training on CHARUSAT High-Performance GPU clusters.
